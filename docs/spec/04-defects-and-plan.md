## 2. 重構計畫（工業級：先規格、後資料、再引擎）
1. **規格凍結**：使用者回覆 Q1–Q3 與 02 的〔用〕欄位處理方式後，00–03 標 v2.0 定版，repo 放 `docs/`。
2. **資料層**：文案改 `data/zh.js`、`data/en.js`，每格 `{text, src}`；角色表、節點表、寶寶模板全進資料，引擎不含任何文案。
3. **引擎**：依 01 §3 狀態機重寫為小型 scene runner（每個 scene 一個 render 函式＋時間軸），取代現在交錯的 async 函式。
4. **資產**：`img/<pack>/`；pack 清單：pencil（鉛筆人）、muse（Muse Image 彩鉛）。缺圖時退回 pencil。
5. **AI**：`proxy/`（Cloudflare Worker）＋前端 `ai.js`（逾時 4 秒→備援）。
6. **測試**：smoke（200 局）＋窮舉 128 路徑平衡表＋文案 lint＋三路實機截圖；全部寫成 `npm test` 一鍵跑，推版前必綠。
7. **追溯**：每個 commit 訊息帶需求 ID（例：`game: C9 opening photo`）。
