## 3. 一局流程（狀態機）
```
TITLE → OPENING → [YEAR ×7: NEWS → SETUP → WALL → (PUBLISH) → REACTION → (LIFE?) → BABY?] → FINAL_WALL → REUNION → VERDICT → SOURCES → END
```
- OPENING（C9、D4）：①2018 群組：同學恭喜老顏找到好工作（3 則，帶身分）。②辦公大樓前六人背對鏡頭高舉右手的合照（全彩），一行字「約好八年後再來這裡拍一張」。③「上班」按鈕。
- NEWS（A6）：新聞剪報一行，真實數字。
- SETUP（C12、A7）：1–2 則群組訊息，由當年相關的同學說出處境做鋪陳（不表態選邊），帶身分標籤。
- WALL（C1、C2）：全寬大圖左右半；買單者第一次出現時角落有一句私事；第一面牆有操作提示文字。滑向一邊＝預覽（彩色＋標語），按「發布」＝確定。不能重選（F1）。
- REACTION：主管便利貼 1 則＋群組 1 則（首則必為被裁者；選右時為受惠者淡淡一句）（D5）。
- LIFE（C4）：只在選右後出現；第 1–3 次各一個新物件（未讀訊息→回診單過期→相框只剩一隻手）；第 4 次起不再新增物件，改為相框再褪一階＋一行字。
- BABY（C10）：每局隨機 2–6 則「本班第 N 位小朋友」動態卡（同學抱嬰兒照＋一句恭喜），插在年與年之間；約每 2–3 年一則；與選擇無關（C7）。總數 = 結尾阿芳說的數字。
- 大事件洗版（D6）：2021 停課與 2026 最後一張，SETUP 改為 4–5 則快速連發。
- FINAL_WALL（C6）：2026 主管「這張妳自己裁」。左＝佩珊請半天陪孩子；右＝老顏與兩疊卷宗（右半畫面依選右次數 0／1–2／3+ 三版）。
- REUNION（C3、C9、G2）：同一棟辦公大樓前，六人轉過身來的合照；被裁過的同學依序起身走出，留下虛線空位；每人說一句代價（數字只在這裡出現），可追問（§6）。老顏若最後一張裁掉自己：她是拿相機的人，走不了，黑白留在畫面。
- VERDICT（G4）：一行斷語標題（例：「妳的宣傳照很好看，合照只剩三個人」），由 AI 依路徑生成；離線時用預寫 8 句。
- SOURCES（A6）：本局走過年份的出處＋AI 使用聲明。
- END：阿芳總結（C8 原句）→「再拍一次」。

## 5. 狀態與規則
- `gone[]`：被裁過的同學（含節點紀錄 `cutIn[name]=[nodes]`）。
- `self`：選右次數（0–6）。生活物件索引 = min(self,3)；相框褪色階 = max(0,self-3)。
- `laoyanGray`：最後一張選左。
- 主管耐心：不設數值、不調職（prop6 規則廢止，避免第二套系統，C14）。
- 平衡檢查（A2）：16 種主幹組合中，不得有「無人走出且老顏 0 格」的路徑；全右路徑老顏結局必須最重；全左路徑走出人數最多。驗收見 §8。

## 6. AI 規格（G1–G4、G6）
- 角色：Muse Spark 1.3（standard，非 contributor，因內容含玩家輸入）。
- 呼叫點 1：REUNION 每位走出的同學的代價句（輸入：角色卡、被裁年份與新聞、老顏 self、本局其他人去留）。
- 呼叫點 2：追問。玩家可點 3 個建議問題或自由輸入（≤40 字），每人最多 3 問；角色內回答；離題（例：費馬大定理）以角色口吻帶回自身處境（G3）；不得說教、不得評價政府真實人物。
- 呼叫點 3：VERDICT 斷語（≤20 字）。
- 架構：靜態頁→中繼站（只接受本遊戲 origin、每 IP 每分鐘 10 次、單局 12 次上限、記帳）→api.meta.ai。【待決 Q3】中繼站平台需使用者帳號（建議 Cloudflare Workers 免費方案）。
- 離線備援：中繼站失敗或逾時 4 秒，改用 data.js 預生成句（現已有 14 組＋8 結局＋固定 3 題），畫面不顯示錯誤。
- 揭示：SOURCES 頁一行「同學會台詞由 Meta Muse Spark 依妳這局的選擇即時生成」。
- 為何不可拿掉（G1 論述）：同學說的是「妳這局」對他做了什麼，路徑組合 × 追問內容無法預寫窮盡。

## 7. 資料與檔案
- `index.html`：引擎（不含文案）。
- `data/zh.js`、`data/en.js`：全部文案，每格標 `src: user|ai-draft`（E1：使用者覆寫後改 user）。
- `img/<pack>/…`：資產包（F6），`pack` 切換一次換全套；預設 pack 由使用者定。
- `tools/`：生成腳本；`proxy/`：中繼站原始碼（不含金鑰）。

## 8. 驗收測試（每次推版必跑，H5）
1. 冒煙 200 局：100% 到結尾、0 JS error、每位走出者都有代價句、老顏結局句存在且只一句。
2. 路徑窮舉（7 節點共 2^7）：輸出走出人數／self 分佈表，檢查 §5 平衡規則。
3. 文案 lint：所有對老顏的第二人稱為「妳」；每則群組訊息有身分標籤；同牆左右不同人；字數上限（群組 24、私事 18、標語 16、代價 45）。
4. 實機截圖自玩：全左、全右、交錯三條，逐一對照 00 表打勾。
5. 英文模式同上 1、4。
