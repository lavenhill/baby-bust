# 03 UI 配置 v2.0（2026-10-27）
原則：單一垂直動態（F1、C14）；結構自己說話（D3）；必要資訊照給（D4）；手機優先 390×780 基準，最寬 440px 置中。

## 1. 全域
- 背景：夜藍 #2F3B52（深夜辦公室）。紙 #F3ECE9、宣傳粉 #E8A9B0、褪粉 #D9B8B8、灰 #9C9898、墨 #3A3434（F5）。
- 字體：宣傳／介面＝圓體（Huninn）；私事、主管便利貼、物件說明＝手寫（LXGW WenKai TC）。中文字體需內嵌或自帶 fallback（實測 Noto CJK）。
- 逐年褪色：每過一年，整條新內容 saturate 1 → .46（7 階）。
- 固定元素只有兩個：左上語言鈕（只在標題頁，開始後移除）、右上卷宗堆（每年＋2 張，選右＋3 張，不可點，F3）。
- 不畫手機狀態列、不放無功能圖示（F3）。

## 3. 互動
- 牆（2026-10-28 使用者核可：放棄滑動，只用點選）：點一下某半＝選中（變文宣，另一半變暗），可改點另一半；按黃條「發布」才確定（兩步）。滑動、滾輪都不再選擇。電腦：滑鼠點選同手機；鍵盤 ↑ 或 1＝上半、↓ 或 2＝下半、Enter 發布。
- 發布手感：剪刀沿兩半中間、靠沒選那半的虛線從左剪到右（約 600ms），沒選那半轉灰、往外掉出畫面（上半往上、下半往下，約 500ms），再進原後果；不加旁白文字。prefers-reduced-motion：不顯示剪刀，沒選那半直接淡出（300ms）。
- 發布後：牆鎖定（不可重選），黃條換成主管一句，點一下進回饋頁。
- 每則出現間隔：一般 700ms、洗版 250ms；整局目標 2–3 分鐘（H4）。

## 4. 版面禁則（本次自玩教訓）
- 年份分隔不重複（同學會用「2026　同學會」）。
- 牆內文字不得蓋臉：私事在右上角、標語在頂、名字說明在底部字帶。
- 同一牆左右不同人。
- 合照只放同學；走出後留虛線空位而非塌陷或亂洞。
- 生活物件不重複同一張圖。

## 5. 英文模式
- 標題頁右上 EN／中文切換；所有欄位有 en 版；英文版角色用英文名並附身分（Amy (parent)；2026-10-28 21:43 起，見 00 §M）。
- 系統語言為英文時預設英文。

## 6. 無障礙與效能
- 圖片 webp 480×960 ≤60KB；首屏只載入開場與 2018 圖，其餘選前不載入（F1）。
- 文字對比 ≥ 4.5:1（灰小字例外只用於出處）。
- 按鈕最小 44×44。
